A Content Delivery Network (CDN) is a global network of "Edge Servers" strategically placed around the world .

Instead of making every single user travel all the way to your main origin server to get data, a CDN stores copies of your content (like images, videos, and code) right in their own backyard. This makes your website load blazing fast for the user and acts as a massive shield so your main server never gets overwhelmed and crashes from too much traffic.
